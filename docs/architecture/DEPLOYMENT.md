# Deployment

A concise production launch procedure for FileSetGo (FSG-007 directive §53).
This is engineering readiness documentation — it does not perform or claim
any actual production deployment, DNS pointing, TLS issuance, or
search-console verification, all of which are external operational actions
(directive §58) outside this coding environment.

## Requirements

- PHP `^8.3` (per `composer.json`; this project's development environment runs PHP 8.5).
- Node.js and npm for the asset build (`package.json` pins `@playwright/test` etc.; no specific Node engine constraint is declared, but CI uses Node v22.23.2/npm 10.9.8 — see `docs/directives/FSG-006.md`).
- Composer for PHP dependencies.
- HTTPS (directive §55) — FileSetGo does not implement its own TLS; terminate TLS at the host/load balancer/CDN.

## Environment variables

Set at minimum:

- `APP_NAME` — public product name.
- `APP_ENV=production` — required for public indexability (directive §19/§20): `robots.txt` and every page's `<meta name="robots">` are environment-aware and default to `noindex`/`Disallow: /` outside `production`.
- `APP_DEBUG=false` — required; a `true` value exposes debug stack traces and must never be used in production (directive §52).
- `APP_URL=https://filesetgo.com` — the canonical production origin (directive §54). Every canonical/Open Graph URL is generated from this via Laravel's `url()`/`route()` helpers, never hard-coded.
- `APP_KEY` — generate with `php artisan key:generate` if not already set.
- Standard database/session/cache variables as appropriate for the target host (this application's default `sqlite`/`database` drivers are suitable for a small deployment; swap via the usual Laravel environment variables for a larger one).

Do not commit `.env` or any secret to the repository.

## Build

```bash
composer install --no-dev --optimize-autoloader
npm ci
npm run build
```

`npm run build` produces `public/build/` (the Vite manifest FileSetGo's `@vite()` calls resolve against). Rebuild whenever a Blade view's Tailwind classes change — the compiled CSS is generated by scanning Blade/TS source at build time, so a class added after the last build will render with no effect until the next build.

## Cache and writable directories

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

Ensure `storage/` and `bootstrap/cache/` are writable by the web server process, per normal Laravel deployment practice.

## Verification (automatable, per ADR-013 / directive §57)

After deploying, run the existing automated suites against the deployed build rather than manual QA:

```bash
php artisan test --compact
vendor/bin/pint --test
npm run typecheck && npm run typecheck:browser
npm run test:core && npm run test:ui
npm run test:browser
```

To confirm the public/SEO surface specifically without a browser, `tests/Feature/PublicSurfacesTest.php` covers: every indexable route returns 200, unique title/description per page, canonical/Open Graph presence, sitemap validity and route coverage, robots.txt behavior, the 404 surface, and that only the homepage loads the processing application bundle.

## Launch smoke test (directive §59)

If a live production deployment is reachable from the coding environment, a narrow smoke test should confirm: homepage 200, CSS/JS load, no fatal JS error, one small Quick Fit workflow, each acquisition page 200, `/sitemap.xml` 200 and valid, `/robots.txt` 200 and referencing the sitemap, HTTPS, canonical host matches `APP_URL`, and no debug output. This has not been executed as part of FSG-007 engineering — see `SPRINT_REPORT.md`'s Production Deployment State section.

## Search engine / webmaster follow-up (external, not engineering)

Once live: submit `https://filesetgo.com/sitemap.xml` to Search Console/Bing Webmaster Tools, and verify the property using whichever method the provider supports (DNS record or a file/meta tag insertion into `resources/views/layouts/public.blade.php`'s `<head>`). This is an external operational step, not a blocker for FSG-007's engineering closure (directive §56/§58).
