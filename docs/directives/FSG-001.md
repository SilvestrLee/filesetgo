# FSG-001 — Core Client Runtime & Safety Foundation

- **Status:** Active
- **Mode:** Product implementation
- **Product:** FileSetGo

## Objective

Prove the actual V1 architecture through this local processing path:

```text
File
→ Preflight
→ Safety
→ Worker
→ Decode
→ Normalize
→ Resize
→ Encode
→ Validate
→ Local Download
```

## Required Outcomes

FSG-001 must deliver and prove:

- the `@filesetgo/core` package;
- a typed worker protocol;
- safe preflight;
- JPEG dimension inspection;
- PNG dimension inspection;
- WebP dimension inspection;
- format signature detection;
- a 15 MB initial source limit;
- a 24 MP initial decoded-dimension limit;
- EXIF orientation handling;
- proportional resize;
- JPEG, PNG, and WebP encoding;
- controlled cancellation;
- a structured error vocabulary;
- a browser-side HEIC technical path;
- zero source-image upload; and
- a development proof UI.

Where a supported format exposes dimensions in headers or container metadata, safety checks must occur before full pixel allocation.

## Non-Goals

FSG-001 does not deliver:

- a target-size optimizer;
- Website Logo Pack;
- a favicon generator;
- presets;
- ZIP packaging;
- PDF processing;
- accounts;
- payments;
- a public API;
- Keryon integration; or
- cross-promotion.

## Governing Constraints

- Supported processing remains on the user's device.
- Heavy processing runs in a worker with one active heavy job initially.
- HEIC V1 input support is required, but the implementation dependency remains subject to maintenance, security, license, worker-compatibility, and memory evaluation.
- SVG is outside this milestone.
- Outputs must be validated before local download.
- Cancellation and completion must release object URLs, image bitmaps, canvases, buffers, and worker-held references that are no longer needed.

## Required Verification

```text
npm run typecheck
npm run test:core
npm run build
php artisan test --compact
git diff --check
```

Passing commands do not replace truthful browser and device verification of the end-to-end processing path.
