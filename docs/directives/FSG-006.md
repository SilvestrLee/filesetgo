# 1. Milestone Objective

FSG-006 does NOT add a new FileSetGo feature.

Its purpose is to verify, harden and certify the existing V1 product
surface:

- Quick Fit
- Guided Fit
- Website Logo Pack
- browser-local image processing
- downloads
- HEIC path
- ZIP path
- cancellation
- stale-result protection
- responsive/mobile behavior
- accessibility behavior
- unsupported-runtime behavior

The milestone asks:

"Does the FileSetGo MVP behave reliably in the browsers and viewport
conditions real users will encounter?"

# 20. HEIC Browser-Level Verification

HEIC is a required V1 input format.

→ Quick Fit or Logo Pack
→ successful output.

# 21. Capability-Gated Unsupported Runtime

Audit behavior when required browser capabilities are missing.

At minimum consider:

- Worker unavailable;
- OffscreenCanvas unavailable;
- createImageBitmap unavailable;
- WebAssembly unavailable where HEIC is requested.

Do not necessarily polyfill everything.

The requirement is:

unsupported capability
→ deterministic detection
→ understandable message
→ no crash
→ no broken half-processing state.

A browser that cannot satisfy the core processing contract should fail
clearly rather than pretend to work.
